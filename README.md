# ربات اخبار فوتبال ایران برای تلگرام

هر روز ساعت ۸ صبح (به وقت ایران)، آخرین اخبار فوتبال ایران را از ورزش۳ جمع‌آوری و به کانال تلگرام شما ارسال می‌کند. کاملاً رایگان و بدون نیاز به سرور، با استفاده از GitHub Actions.

---

## مرحله ۱: ساخت بات تلگرام

1. در تلگرام به [@BotFather](https://t.me/BotFather) پیام بدهید.
2. دستور `/newbot` را بفرستید.
3. یک اسم برای بات انتخاب کنید (مثلاً: اخبار فوتبال ایران).
4. یک یوزرنیم انتخاب کنید که باید به `bot` ختم شود (مثلاً: `iranfootballnews_bot`).
5. BotFather یک **توکن** به شما می‌دهد، شبیه این:
   ```
   123456789:AAHk3jKl9-examplE_Token_xyz
   ```
   این توکن را جایی امن ذخیره کنید — معادل رمز عبور بات شماست.

## مرحله ۲: اضافه کردن بات به کانال

1. وارد کانال تلگرام خودتان شوید.
2. از بخش مدیریت کانال (Administrators)، بات جدید را به عنوان **ادمین** اضافه کنید.
3. حتماً دسترسی **Post Messages** را برای بات فعال کنید.

## مرحله ۳: پیدا کردن Chat ID کانال

- اگر کانال **پابلیک** است: همان `@نام_کاربری_کانال` را به عنوان Chat ID استفاده کنید.
- اگر کانال **خصوصی** است:
  1. یک پیام دلخواه در کانال بفرستید (یا فوروارد کنید).
  2. در مرورگر این آدرس را باز کنید (به‌جای `<TOKEN>` توکن بات را بگذارید):
     ```
     https://api.telegram.org/bot<TOKEN>/getUpdates
     ```
  3. در خروجی JSON، دنبال `"chat":{"id":-1001234567890...}` بگردید. همین عدد (با علامت منفی) Chat ID شماست.

## مرحله ۴: ساخت ریپازیتوری در گیت‌هاب

1. اگر حساب گیت‌هاب ندارید، در [github.com](https://github.com) ثبت‌نام کنید (رایگان).
2. یک ریپازیتوری جدید بسازید (می‌تواند Private باشد).
3. تمام فایل‌های این پروژه (`fetch_and_send.py`، `requirements.txt`، پوشه‌ی `.github/workflows/`) را در آن آپلود کنید.
   - ساده‌ترین راه: از دکمه‌ی "Add file → Upload files" در صفحه‌ی گیت‌هاب استفاده کنید و کل پوشه را بکشید و رها کنید. حتماً ساختار پوشه‌ی `.github/workflows/daily-football-news.yml` حفظ بشه.

## مرحله ۵: تنظیم Secrets (توکن و Chat ID)

1. در ریپازیتوری گیت‌هاب: `Settings → Secrets and variables → Actions → New repository secret`
2. دو Secret بسازید:
   - نام: `TELEGRAM_BOT_TOKEN` — مقدار: توکنی که از BotFather گرفتید
   - نام: `TELEGRAM_CHAT_ID` — مقدار: Chat ID کانال (مرحله ۳)

## مرحله ۶: تست اجرای دستی

1. به تب **Actions** در ریپازیتوری بروید.
2. روی workflow با نام "Daily Iran Football News to Telegram" کلیک کنید.
3. دکمه‌ی **Run workflow** را بزنید.
4. بعد از چند ثانیه لاگ اجرا را چک کنید — اگر پیام "پیام با موفقیت ارسال شد" را دیدید، یعنی همه‌چیز درست است و باید پیام در کانالتان ظاهر شده باشد.

از این به بعد، اسکریپت هر روز ساعت ۸:۰۰ صبح به‌وقت ایران به‌صورت خودکار اجرا می‌شود — بدون نیاز به هیچ سروری.

---

## نکات

- **تغییر ساعت ارسال:** در فایل `.github/workflows/daily-football-news.yml`، مقدار `cron: "30 4 * * *"` را عوض کنید (زمان به وقت UTC است؛ ایران UTC+3:30 است).
- **تغییر تعداد اخبار:** در `fetch_and_send.py`، مقدار `MAX_ITEMS` را تغییر دهید.
- **افزودن کلیدواژه‌های بیشتر:** لیست `FOOTBALL_KEYWORDS` در `fetch_and_send.py` را می‌توانید گسترش دهید (مثلاً اسم بازیکنان یا باشگاه‌های موردعلاقه‌تان).
- **منبع خبر:** فعلاً فقط RSS ورزش۳ استفاده می‌شود. اگر بخواهید منبع دوم (مثلاً فوتبالی یا طرفداری) اضافه شود، به من بگویید تا کد را گسترش بدهم.
- زمان‌بندی GitHub Actions گاهی چند دقیقه تأخیر دارد (طبیعی است، مخصوص پلن رایگانه).
